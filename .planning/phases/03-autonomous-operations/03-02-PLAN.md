Create `src/circuit_breaker.py` with three public functions:

**1. `get_cb_status() -> CircuitBreakerState`**
Read the circuit_breaker table (id=1) from SQLite. Return a `CircuitBreakerState` dataclass. If HALTED_DAILY and the `tripped_at` date is before today, auto-reset to ACTIVE (daily loss resets each day per ARCHITECTURE.md state machine). Update the DB row if auto-reset occurs.

```python
def get_cb_status() -> CircuitBreakerState:
    conn = get_db()
    try:
        row = conn.execute("SELECT * FROM circuit_breaker WHERE id=1").fetchone()
        if not row:
            return CircuitBreakerState()

        status = row["status"]
        tripped_at = row["tripped_at"]

        # HALTED_DAILY auto-resets on new calendar day
        if status == "HALTED_DAILY" and tripped_at:
            tripped_date = tripped_at[:10]  # YYYY-MM-DD
            today = datetime.now().strftime("%Y-%m-%d")
            if tripped_date < today:
                conn.execute(
                    "UPDATE circuit_breaker SET status='ACTIVE', reset_at=? WHERE id=1",
                    (datetime.now().isoformat(),),
                )
                conn.commit()
                logger.info("HALTED_DAILY auto-reset (tripped {}, now {})", tripped_date, today)
                return CircuitBreakerState(status="ACTIVE", reset_at=datetime.now().isoformat())

        return CircuitBreakerState(
            status=status,
            tripped_at=tripped_at,
            reason=row["reason"],
            reset_at=row["reset_at"],
        )
    finally:
        conn.close()
```

**2. `evaluate_circuit_breaker(opening_nlv: float, current_nlv: float) -> CircuitBreakerState`**
Given the opening NLV (start-of-day) and current NLV (post-trade), evaluate whether a trip condition is met.

Logic:
a. Get current CB status. If already tripped, return it unchanged.
b. Compute daily P&L: `daily_pnl_pct = (current_nlv - opening_nlv) / opening_nlv` if opening_nlv > 0.
c. If `daily_pnl_pct < -settings.max_daily_loss_pct` (e.g., loss > 10%): trip to HALTED_DAILY.
d. Get peak equity from daily_snapshots: `SELECT MAX(peak_equity) FROM daily_snapshots`. If no rows, use opening_nlv as peak.
e. Compute drawdown: `drawdown_pct = (peak - current_nlv) / peak` if peak > 0.
f. If `drawdown_pct > settings.max_drawdown_pct` (e.g., > 30%): trip to HALTED_DRAWDOWN.
g. If tripped, update SQLite circuit_breaker row:
```python
conn.execute(
    "UPDATE circuit_breaker SET status=?, tripped_at=?, reason=? WHERE id=1",
    (new_status, datetime.now().isoformat(), reason_str),
)
conn.commit()
logger.error("CIRCUIT BREAKER TRIPPED: {} -- {}", new_status, reason_str)
```
h. Return the CircuitBreakerState.

**3. `record_daily_snapshot(snapshot: AccountSnapshot, previous_nlv: float | None = None) -> DailySnapshot`**
Record today's equity snapshot in daily_snapshots table. Compute peak equity and drawdown.

Logic:
a. Get previous peak: `SELECT MAX(peak_equity) FROM daily_snapshots`. Default to current NLV if no rows.
b. `new_peak = max(previous_peak, snapshot.net_liquidating_value)`.
c. `drawdown_pct = (new_peak - snapshot.net_liquidating_value) / new_peak` if new_peak > 0, else 0.
d. `positions_value = sum(p["market_value"] for p in snapshot.positions)`.
e. If `previous_nlv` provided: `daily_pnl = snapshot.net_liquidating_value - previous_nlv`, `daily_pnl_pct = daily_pnl / previous_nlv`. Else get yesterday's snapshot from DB.
f. INSERT OR REPLACE into daily_snapshots (keyed on snapshot_date = today's date).
g. Return a `DailySnapshot` dataclass.
