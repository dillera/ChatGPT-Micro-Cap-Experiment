    - Tickers with market_cap > $300M are excluded
    - Tickers with average volume < 10K are excluded
    - Tickers on OTC exchanges are excluded (via otc_filter.validate_symbols)
    - Results are cached in SQLite screener_cache table; re-screening within cache TTL returns cached results
    - get_screener_candidates() aggregates results from all configured sectors
  </behavior>
  <action>
1. Add screener settings to src/config.py Settings class:
   ```python
   # Screener settings (Phase 6)
   screener_sectors: list[str] = ["biotech", "tech"]
   screener_max_market_cap: float = 300_000_000  # $300M
   screener_min_volume: int = 10_000             # 10K avg daily volume
   screener_cache_hours: int = 24                # Cache TTL
   screener_max_results_per_sector: int = 20     # Cap results
   ```

2. Add screener_cache table to SCHEMA_SQL in src/db.py:
   ```sql
   CREATE TABLE IF NOT EXISTS screener_cache (
       id          INTEGER PRIMARY KEY AUTOINCREMENT,
       sector      TEXT NOT NULL,
       symbol      TEXT NOT NULL,
       market_cap  REAL,
       avg_volume  REAL,
       exchange    TEXT,
       cached_at   TEXT NOT NULL
   );
   CREATE INDEX IF NOT EXISTS idx_screener_cache_sector ON screener_cache(sector);
   ```

3. Create src/screener.py with:
   - `screen_sector(sector: str) -> list[str]`:
     a. Check screener_cache for this sector where cached_at is within cache_hours TTL.
     b. If cache hit, return cached symbols.
     c. If cache miss, use yfinance to screen. Approach: use `yf.Screener` if available, otherwise use a curated sector-to-tickers mapping with `yf.Tickers()` to batch-fetch info. For reliability, use the approach:
        - Define sector query strings: `{"biotech": "ms_basic_materials", "tech": "ms_technology"}` or similar yfinance screener keys.
        - Use `yf.screen()` or fall back to `yf.Screener('most_actives')` and filter.
        - NOTE: yfinance screening API changes frequently. The robust approach: maintain a small list of sector ETF holdings or use `yf.Ticker(symbol).info` to validate individual candidates. Since yfinance's screener is unreliable, use a pragmatic approach:
          1. Query `yf.Screener` with predefined queries for small-cap stocks.
          2. Filter results by: market_cap < max, avg_volume > min.
          3. Get exchange info via `yf.Ticker(symbol).info.get("exchange")`.
        - If yfinance screener fails, return empty list and log warning (screener is additive, not critical).
     d. Pass results through `otc_filter.validate_symbols()` to remove OTC tickers.
     e. Cache validated results in screener_cache (DELETE old sector rows, INSERT new).
     f. Return list of validated ticker strings.

   - `get_screener_candidates() -> list[str]`:
     a. Read `settings.screener_sectors`.
     b. Call `screen_sector(sector)` for each.
     c. Deduplicate and return combined list.
