<objective>
Add LLM-based ticker discovery (a separate prompt asking LLMs to suggest new candidates) and wire all three candidate sources (watchlist, screener, LLM proposals) into the daily trading cycle. The cycle now gathers candidates from all sources, deduplicates against existing positions, validates through OTC filter, and runs consensus on each.

Purpose: Completes the candidate pipeline so the bot can discover and trade NEW tickers rather than only analyzing existing positions. This is the core value-add of Phase 6.

Output: Extended `src/prompts.py`, `src/consensus.py`, `src/cycle.py`, plus discovery tests.
</objective>
