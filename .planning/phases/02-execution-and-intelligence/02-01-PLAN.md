```python
from pydantic import BaseModel, Field
from typing import Literal

class TradeRecommendation(BaseModel):
    """Schema for LLM trading response. Used with native structured output."""
    action: Literal["BUY", "SELL", "HOLD"]
    symbol: str = Field(description="Ticker symbol, e.g. RXRX")
    confidence: float = Field(ge=0.0, le=1.0, description="0.0-1.0 conviction level")
    stop_loss_pct: float = Field(ge=0.01, le=0.50, description="Stop loss as % below entry")
    reasoning: str = Field(max_length=500, description="2-3 sentence rationale")

class TradingAnalysis(BaseModel):
    """Top-level response schema for each LLM."""
    market_assessment: str = Field(max_length=300)
    recommendations: list[TradeRecommendation]

class ConsensusResult(BaseModel):
    """Output of the consensus engine for downstream consumers."""
    approved_trades: list[TradeRecommendation]
    bull_analysis: TradingAnalysis
    bear_analysis: TradingAnalysis
    all_symbols_seen: list[str]
    disagreed_symbols: list[str]
```

Create `src/consensus.py` with these functions:

1. `query_bull(prompt: str) -> TradingAnalysis` -- calls OpenAI `client.chat.completions.parse()` with:
   - `model=settings.openai_model` (default "gpt-5.4-mini")
   - `messages=[{"role": "system", "content": BULL_SYSTEM}, {"role": "user", "content": prompt}]`
   - `response_format=TradingAnalysis`
   - `temperature=settings.consensus_temperature`
   - `max_tokens=settings.consensus_max_tokens`
   - Returns `completion.choices[0].message.parsed`

2. `query_bear(prompt: str) -> TradingAnalysis` -- calls Anthropic `client.messages.parse()` with:
   - `model=settings.anthropic_model` (default "claude-sonnet-4-6")
   - `system=BEAR_SYSTEM`
   - `messages=[{"role": "user", "content": prompt}]`
   - `output_format=TradingAnalysis`
   - `max_tokens=settings.consensus_max_tokens`
   - Returns `response.parsed_output`

3. `evaluate_consensus(bull: TradingAnalysis, bear: TradingAnalysis, min_confidence: float = 0.6) -> tuple[list[TradeRecommendation], list[str]]`:
   - Build dicts keyed by symbol from each analysis's recommendations
   - For each symbol in the union of both dicts:
     - If only one model mentions it: log info, skip (disagreed)
     - If actions differ: log info, skip (disagreed)
     - If `min(bull.confidence, bear.confidence) < min_confidence`: log info, skip (low confidence)
     - Otherwise: create approved TradeRecommendation using min confidence and max stop_loss_pct (more conservative)
   - Returns (approved_trades, disagreed_symbols)

4. `_log_llm_call(conn, model: str, prompt: str, raw_response: str, parsed_ok: bool, parse_error: str | None = None) -> int`:
   - Inserts into `llm_audit` table with `hashlib.sha256(prompt.encode()).hexdigest()` as prompt_hash
   - Returns the inserted row id

5. `_log_consensus(conn, gpt4_audit_id: int, claude_audit_id: int, agreed: list[str], disagreed: list[str]) -> int`:
   - Inserts into `consensus_decisions` table
   - Returns the inserted row id

6. `run_consensus_cycle(positions: list[dict], buying_power: float, candidates: list[str]) -> ConsensusResult`:
   - Calls `build_user_prompt(positions, buying_power, candidates)`
   - Calls `query_bull(prompt)` -- if raises, log error and re-raise (NO fallback)
   - Calls `query_bear(prompt)` -- if raises, log error and re-raise (NO fallback)
   - Logs both raw responses to llm_audit via `_log_llm_call`
   - Calls `evaluate_consensus(bull, bear, settings.min_confidence)`
   - Logs consensus decision via `_log_consensus`
   - Returns `ConsensusResult(approved_trades=approved, bull_analysis=bull, bear_analysis=bear, all_symbols_seen=all_symbols, disagreed_symbols=disagreed)`
